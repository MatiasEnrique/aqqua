# File attachments

Drop files onto the message composer to attach them. aqqua accepts images, documents, archives,
audio, video, and other file types. You can attach up to eight files to one message, and each file
can be up to 10 MB.

Images appear as previews. Other files appear by name and can be opened from the conversation after
the environment stores them. Attachments also work in queued and stashed messages.

The environment stores the uploaded bytes and gives the selected provider access to that stored
file. This also works when the browser or mobile client connects to a remote environment because the
file travels through the aqqua connection rather than relying on a path from the client device.
